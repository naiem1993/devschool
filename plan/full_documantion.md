৩. টার্গেট ইউজার ও তাদের রোল

রোল বিবরণ কী করতে পারবে?
অ্যাডমিন সাইটের একমাত্র মালিক (আমি) টিউটোরিয়াল, কুইজ, চ্যালেঞ্জ, রেফারেন্স যোগ/সম্পাদনা/ডিলিট
গেস্ট ইউজার যে কেউ সাইট ভিজিট করবে লগইন ছাড়াই সব টিউটোরিয়াল, প্লেগ্রাউন্ড, কুইজ, চ্যালেঞ্জ দেখতে ও ব্যবহার করতে পারবে

৫. ইউজার ফ্লো/জার্নি

ইউজার (গেস্ট) ফ্লো:

1. হোমপেজে আসে → ক্যাটাগরি ও জনপ্রিয় টিউটোরিয়াল দেখে।
2. ক্যাটাগরি ক্লিক করে → সেই ক্যাটাগরির সব টিউটোরিয়ালের তালিকা দেখে।
3. টিউটোরিয়াল ক্লিক করে → টিউটোরিয়াল কন্টেন্ট পড়ে, পাশে সাইডবারে অধ্যায়ের তালিকা দেখে।
4. প্লেগ্রাউন্ড ব্যবহার করে → লাইভ কোড এডিটরে কোড লিখে আউটপুট দেখে।
5. কুইজ দেয় → টিউটোরিয়াল শেষে mcq তে অংশ নেয়, সঠিক উত্তর দিলে অটোসবাজি অ্যানিমেশন দেখে।
6. চ্যালেঞ্জ সাবমিট করে → কোড লিখে সাবমিট করলে টেস্ট কেস চেক হয়ে ফিডব্যাক পায়।
7. রেফারেন্স দেখে → প্রয়োজনে ট্যাগ/ফাংশনের ডকুমেন্টেশন দেখে।
8. দান করে → চাইলে ডোনেশন বাটন থেকে দান করে।- এইটা ও এডমিন প্যানেল থেকে on off করার সিস্টেম লাগবে 

অ্যাডমিন ফ্লো (বর্তমানে সরাসরি ডাটাবেস/Prisma Studio দিয়ে):

1. Prisma Studio বা pgAdmin দিয়ে ক্যাটাগরি, টিউটোরিয়াল, কুইজ, চ্যালেঞ্জ, রেফারেন্স যোগ/সম্পাদনা/ডিলিট করে।

৬. ডিজাইন ও ইউজার ইন্টারফেসের নির্দেশনা

থিম ও কালার:

· প্রাইমারি কালার: ইন্ডিগো/পার্পল গ্রেডিয়েন্ট (from-indigo-600 to-purple-600)
· ব্যাকগ্রাউন্ড: সাদা (লাইট মোড), #0a0a0a (ডার্ক মোড)
· টেক্সট: ধূসর (লাইট), হালকা ধূসর (ডার্ক)
· অ্যাকসেন্ট: ইন্ডিগো, হলুদ (হিরোতে)

ডিজাইন সিস্টেম:

· টাইপোগ্রাফি: Geist Font (Next.js ডিফল্ট)
· কম্পোনেন্ট: Tailwind CSS দিয়ে বানানো, dark: ক্লাস ব্যবহার করা হয়েছে
· কার্ড: রাউন্ডেড, হোভার ইফেক্ট (শ্যাডো + স্কেল)
· বাটন: রাউন্ডেড, গ্রেডিয়েন্ট, হোভার ইফেক্ট
· সাইডবার: টিউটোরিয়াল পেজে বাম পাশে, অধ্যায়ের তালিকা

লেআউট:

· হোমপেজ: হিরো সেকশন → ক্যাটাগরি কার্ড → জনপ্রিয় টিউটোরিয়াল → সর্বশেষ টিউটোরিয়াল →
· টিউটোরিয়াল ডিটেইল: হোমপেজে কোনো  সাইডবার (বাম) + কন্টেন্ট (ডান) থাকবে না হোম পেজে সারচ বার থাকবে সুন্দর করে।
· ক্যাটাগরি পেজ: ক্যাটাগরি টাইটেল + টিউটোরিয়াল লিস্ট
· প্লেগ্রাউন্ড: কোড এডিটর (বাম) + আউটপুট (ডান)

৮. তথ্যভাণ্ডার (ডাটাবেজ) এর সম্ভাব্য স্ট্রাকচার

টেবিলসমূহ (Prisma Schema):

```prisma
// ==========================================
//  CATEGORY
// ==========================================
model Category {
  id          String   @id @default(cuid())
  name        String   @unique
  slug        String   @unique
  description String?
  icon        String?
  createdAt   DateTime @default(now())

  tutorials   Tutorial[]
  references  Reference[]
}

// ==========================================
//  TUTORIAL
// ==========================================
model Tutorial {
  id          String   @id @default(cuid())
  title       String
  slug        String   @unique
  content     String   @db.Text
  categoryId  String   @map("category_id")
  category    Category @relation(fields: [categoryId], references: [id])
  difficulty  String   @default("beginner")
  isPublished Boolean  @default(true)
  views       Int      @default(0)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  exercises   Exercise[]
  quizzes     Quiz[]
}

// ==========================================
//  EXERCISE (প্র্যাকটিস)
// ==========================================
model Exercise {
  id          String   @id @default(cuid())
  tutorialId  String   @map("tutorial_id")
  tutorial    Tutorial @relation(fields: [tutorialId], references: [id])
  question    String   @db.Text
  hint        String?  @db.Text
  solution    String?  @db.Text
  language    String   @default("javascript")
  createdAt   DateTime @default(now())
}

// ==========================================
//  QUIZ
// ==========================================
model Quiz {
  id          String   @id @default(cuid())
  title       String
  tutorialId  String?  @map("tutorial_id")
  tutorial    Tutorial? @relation(fields: [tutorialId], references: [id])
  description String?
  createdAt   DateTime @default(now())

  questions   QuizQuestion[]
}

model QuizQuestion {
  id          String   @id @default(cuid())
  quizId      String   @map("quiz_id")
  quiz        Quiz     @relation(fields: [quizId], references: [id])
  question    String   @db.Text
  options     String   @db.Text   // JSON array: ["A", "B", "C", "D"]
  correctIndex Int
  explanation String?  @db.Text
  createdAt   DateTime @default(now())
}

// ==========================================
//  CHALLENGE
// ==========================================
model Challenge {
  id          String   @id @default(cuid())
  title       String
  description String   @db.Text
  language    String   @default("javascript")
  starterCode String?  @db.Text
  difficulty  String   @default("easy")
  points      Int      @default(10)
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())

  testCases   ChallengeTestCase[]
}

model ChallengeTestCase {
  id          String   @id @default(cuid())
  challengeId String   @map("challenge_id")
  challenge   Challenge @relation(fields: [challengeId], references: [id])
  input       String   @db.Text
  expectedOutput String @db.Text
  isHidden    Boolean  @default(false)
}

// ==========================================
//  REFERENCE
// ==========================================
model Reference {
  id          String   @id @default(cuid())
  title       String
  slug        String   @unique
  content     String   @db.Text
  categoryId  String?  @map("category_id")
  category    Category? @relation(fields: [categoryId], references: [id])
  language    String
  isPublished Boolean  @default(true)
  views       Int      @default(0)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
```

Index যোগ করা (গতির জন্য):

```prisma
  @@index([slug])
  @@index([views])
  @@index([createdAt])
}

  // ...
  @@index([slug])
}
```

দিক প্ল্যান

📌 ডেভেলপারদের জন্য বিশেষ নির্দেশনা

1. শুরুতে backend ও frontend — দুটি ফোল্ডার আলাদা।
2. backend/prisma/schema.prisma পরিবর্তন করলে frontend-এ কপি করে npx prisma generate চালাতে হবে।

5. ক্যাশিং: সব পেজে revalidate দেয়া হয়েছে — ডাটাবেস চাপ কমাতে।
