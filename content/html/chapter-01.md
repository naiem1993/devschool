# Chapter 1: HTML পরিচিতি — একদম শুরু

**লক্ষ্য:** HTML কী, কেন দরকার — সেটা বোঝা, আর প্রথম একটা page নিজে বানানো।

---

## 1.1 HTML কী?

### ১. সহজ পরিচয়
HTML হলো একটা ভাষা, যা দিয়ে আমরা website বানাই। তুমি ব্রাউজারে যা দেখো — লেখা, ছবি, বাটন — সব HTML দিয়ে তৈরি। এটা প্রোগ্রামিং ভাষা নয়, এটা শুধু বলে দেয় কোন জিনিস কোথায় বসবে।

### ২. বাস্তব জীবনের উদাহরণ
ভাবো তুমি একটা নতুন ঘর বানাচ্ছো। প্রথমে দরজা, জানালা, দেয়াল — কাঠামো বানাতে হয়। তারপর আসে রঙ, আসবাব। Website-এও ঠিক তাই — HTML হলো সেই দেয়াল আর দরজা।

### ৩. Syntax

```
<tag>লেখা</tag>
```

খোলা tag → লেখা → বন্ধ tag। বন্ধ tag-এ `/` থাকে।

### ৪. Code Example

```html
<!DOCTYPE html>
<html>
<body>
  <h1>আমার প্রথম পেজ</h1>
  <p>এটা আমার লেখা প্রথম লাইন।</p>
</body>
</html>
```

### ৫. Output / Result
ব্রাউজারে বড় মোটা অক্ষরে দেখাবে — আমার প্রথম পেজ। তার নিচে ছোট অক্ষরে — এটা আমার লেখা প্রথম লাইন।

### ৬. লাইন-বাই-লাইন ব্যাখ্যা
- `<!DOCTYPE html>` → ব্রাউজারকে বলে এটা আধুনিক HTML ফাইল।
- `<html>` → পুরো page-এর শুরু।
- `<body>` → যা দেখাবে, সব এর ভেতরে থাকে।
- `<h1>আমার প্রথম পেজ</h1>` → বড় শিরোনাম।
- `<p>...প্রথম লাইন।</p>` → ছোট paragraph।
- `</body></html>` → body আর html এখানে শেষ।

### ৭. Try It Yourself

<html>

  <h1>আমার প্রথম পেজ</h1>

</body>

ভেতরের লেখা বদলে তোমার নিজের নাম লেখো, তারপর দেখো কী হয়।

৩. এক লাইনে লেখো: ব্রাউজারে যা দেখি, তার কাঠামো কোন ভাষা দিয়ে বানাই?

ইঙ্গিত: `<h1>` দিয়ে নাম, `<p>` দিয়ে বাক্য।

## 1.2 HTML দিয়ে কী কী বানানো যায়?

### ১. সহজ পরিচয়
HTML দিয়ে যেকোনো website-এর কাঠামো বানানো যায় — ব্যক্তিগত blog থেকে বড় অনলাইন শপ। যা যা দেখা যায়, সবই HTML দিয়ে সাজানো যায়।

### ২. বাস্তব জীবনের উদাহরণ
ভাবো একটা স্কুলের নোটিশ বোর্ড। উপরে বড় করে লেখা থাকে স্কুলের নাম, তার নিচে নোটিশ, পাশে ছবি। একটা website-ও ঠিক এভাবে সাজানো — শুধু পার্থক্য হলো এটা কাগজে নয়, স্ক্রিনে।

### ৩. Syntax
এখানে নতুন syntax নেই — আগের মতোই `<tag>লেখা</tag>`। শুধু কোন কোন জিনিস বসানো যায়, সেটা দেখছি।

### ৪. Code Example

```html
<h1>আমার ব্লগ</h1>
<p>আজ আমি HTML শিখলাম।</p>
<img src="photo.jpg" alt="আমার ছবি">
```

### ৫. Output / Result
ব্রাউজারে উপরে বড় শিরোনাম দেখাবে — আমার ব্লগ। নিচে একটা লাইন লেখা, তার নিচে একটা ছবি (ছবি ফাইল ঠিক থাকলে)।

### ৬. লাইন-বাই-লাইন ব্যাখ্যা
- `<h1>আমার ব্লগ</h1>` → page-এর বড় শিরোনাম।
- `<p>...শিখলাম।</p>` → একটা লেখার লাইন।
- `<img ...>` → ছবি বসানোর tag। এটা বন্ধ tag লাগে না।
- `src="photo.jpg"` → ছবির ফাইলের নাম।
- `alt="আমার ছবি"` → ছবি না দেখা গেলে এই লেখা দেখাবে।

### ৭. Try It Yourself

[[tryit]]
<!DOCTYPE html>
<html>
<body>
  <h1>আমার ব্লগ</h1>
  <p>আজ আমি HTML শিখলাম।</p>
</body>
</html>
[[/tryit]]

শিরোনামটা বদলে তোমার ব্লগের নাম লেখো।

৩. এক লাইনে: ছবি না দেখা গেলে কোন লেখা দেখাবে?

</details>

### 🎯 Practice Task
একটা page বানাও যাতে একটা শিরোনাম, একটু লেখা, আর একটা ছবি থাকবে।
ইঙ্গিত: `<h1>`, `<p>`, `<img>` — তিনটা tag একসাথে।

## 1.3 প্রথম HTML ফাইল — তৈরি ও সেভ

### ১. সহজ পরিচয়
HTML কোড লেখার জন্য দামি সফটওয়্যার লাগে না। যেকোনো Notepad বা Text Editor দিয়েই শুরু করা যায়। লিখে ফাইলটা `.html` নামে সেভ করলেই হয়ে যায়।

### ২. বাস্তব জীবনের উদাহরণ
ভাবো তুমি একটা চিঠি লিখছো। খাতায় লিখে খামে ভরে নাম লিখে দাও — তারপর যাকে পাঠাবে সে পড়তে পারে। HTML ফাইলও তাই — code লিখে `.html` নাম দিয়ে সেভ করলে ব্রাউজার সেটা পড়তে পারে।

### ৩. Syntax
ফাইলের নাম সবসময় `.html` দিয়ে শেষ হবে। যেমন:

```
index.html
about.html
contact.html
```

### ৪. Code Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>আমার সাইট</title>
</head>
<body>
  <h1>স্বাগতম!</h1>
  <p>এটা আমার প্রথম পূর্ণ পেজ।</p>
</body>
</html>
```

### ৫. Output / Result
ব্রাউজারে page-এর উপরে tab-এ দেখাবে — আমার সাইট। ভেতরে বড় করে লেখা — স্বাগতম!, তার নিচে ছোট লেখা।

### ৬. লাইন-বাই-লাইন ব্যাখ্যা
- `<head>` → page-এর তথ্য এখানে থাকে, নিজে দেখা যায় না।
- `<title>আমার সাইট</title>` → ব্রাউজার tab-এ যে নাম দেখাবে।
- `<body>` → যা চোখে দেখা যাবে, সব এখানে।
- বাকি সব আগের মতোই।

### ৭. Try It Yourself

[[tryit]]
<!DOCTYPE html>
<html>
<head>
  <title>আমার সাইট</title>
</head>
<body>
  <h1>স্বাগতম!</h1>

</body>
</html>
[[/tryit]]

`<title>`-এর লেখা বদলে দেখো — উপরের tab-এ কী বদলায়।

### ৮. ছোট Quiz

২. ব্রাউজার tab-এর নাম কোন tag-এ থাকে? (ক) `<h1>` (খ) `<title>` (গ) `<p>`
৩. এক লাইনে: `<head>`-এর ভেতরের জিনিস ব্রাউজারে দেখা যায় কি?

<details>

২. (খ) `<title>`
৩. না — `<head>`-এর জিনিস দেখা যায় না, শুধু তথ্য হিসেবে থাকে।

</details>

### 🎯 Practice Task
একটা ফাইল বানাও নাম দিয়ে `about.html`। তাতে `about` শিরোনাম আর নিজের পরিচয় লিখো।
ইঙ্গিত: `<head><title>` + `<body>` — দুই অংশ ভাগ করে লিখো।
