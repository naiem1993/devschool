---CHALLENGE---
TITLE: দুই সংখ্যার যোগফল || Sum of Two Numbers
DESC: একটি function লিখুন যা দুইটি সংখ্যা যোগ করে return করে। || Write a function that returns the sum of two numbers.
LEVEL: Easy
POINTS: 10
STARTER:
function add(a, b) {
  // your code here
}
END
SOLUTION:
function add(a, b) {
  return a + b
}
END
TEST: 2, 3 => 5
TEST: 10, 20 => 30
TEST_HIDDEN: 100, -50 => 50
TEST_HIDDEN: 0, 0 => 0
---CHALLENGE---
TITLE: জোড়-বিজোড় নির্ণয় || Even or Odd
DESC: একটি function লিখুন যা সংখ্যা জোড় হলে "even", বিজোড় হলে "odd" return করে। || Write a function that returns "even" if the number is even, else "odd".
LEVEL: Easy
POINTS: 5
STARTER:
function check(n) {
  // your code
}
END
SOLUTION:
function check(n) {
  return n % 2 === 0 ? "even" : "odd"
}
END
TEST: 4 => even
TEST: 7 => odd
TEST_HIDDEN: 0 => even
---CHALLENGE---
TITLE: বড় সংখ্যা বের করুন || Find the Largest Number
DESC: একটি function লিখুন যা তিনটি সংখ্যার মধ্যে বড়টি return করে। || Write a function that returns the largest of three numbers.
LEVEL: Medium
POINTS: 20
STARTER:
function largest(a, b, c) {
  // your code here
}
END
SOLUTION:
function largest(a, b, c) {
  return Math.max(a, b, c)
}
END
TEST: 1, 2, 3 => 3
TEST: 10, 5, 8 => 10
TEST_HIDDEN: -1, -5, -3 => -1
